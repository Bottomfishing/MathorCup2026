# 来源补充核验（2026-10-24）

原研究：[Schreurs等，2024，Nature Communications](https://pmc.ncbi.nlm.nih.gov/articles/PMC10966102/)，DOI 10.1038/s41467-024-46346-0。本轮网页访问遇验证页后，通过[Europe PMC公开全文XML接口](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10966102/fullTextXML)读取方法段落。

方法确认：感官采用七级强度量表；评分按品评员中心化和标准差缩放；各场次出席人员不完全相同。因此当前聚合标签不足以唯一恢复原始评分。

作者亦讨论相关化合物替代、风格化学特征及高浓度预测平台效应。我们据此将模型依赖与化学机制分开，并限制生成/迁移结论的适用范围；没有借用原作者模型结果充作本队结果。
