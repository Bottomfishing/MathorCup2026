## 固定的选择规则

沿用已完成的全数据稳健Ridge：训练中位数填补、asinh压缩、标准化X、alpha=1000，按每个目标的系数绝对值选3项，排除已有规则中的12项整体性质或综合指标。同分按附件特征原顺序。没有因参考描述或稳定性不理想而替换排名。

Ridge各目标分别拟合系数，不共享森林的多输出分裂目标；不同目标尺度不影响同一目标内的系数排序。系数表示变换后输入增加一个标准差对应的条件线性关联，不是原始浓度增加一单位的效应。

附件2重建Spearman共变图，阈值|rho|≥0.6时231节点、266边。每条候选附节点度、连通分量大小、最多3个直接邻居及带符号相关系数。图用于揭示相关替代，不作为排名加分项。网络阈值0.5/0.6/0.7的既有敏感性结果分别为645/266/109边。题面所称Pearson与附件实测Spearman的差异沿用数据审计结论，不混用。

全数据图和Ridge排名属于描述性分析，不能称为独立测试集上的因素发现。预测质量与全局/同风格森林置换作为对照，不与系数混成一个未经验证的总分。

## 化学合理性如何解释

采用保守、公开的词表核对规则，输出三类标记：

- `named_marker_matches_target`：目标名称或直接理化指标对应，8条。
- `reference_descriptor_overlap`：原研究风味描述与目标词义有交集，28条。
- `target_specific_evidence_insufficient`：本次参考描述核对未获得目标特异的直接支持，114条。

词表是人工指定的描述一致性检查，不能视为穷尽的感官本体或独立实验验证。未匹配不意味着化学作用不存在；匹配也不能证明该物质在本数据中的因果贡献。此处没有把ASBC或Good Scents二级引用当成已独立访问核实的实验结果。原研究也指出同来源物质存在共变，且复杂风味涉及多种物质互动，支持对代理变量作谨慎解释。[原研究正文](https://www.nature.com/articles/s41467-024-46346-0.pdf)

可直接使用的例子：

| 目标 | 模型Top-3及解释 |
|---|---|
| 麦芽总体香气 | 2-acetylfuran、Methylpyrazine、5-methylfurfural；参考描述与麦芽子风味一致，但第三项重训入选率仅0.395 |
| 酸度 | Lactic acid、Acetic acid、Perillyl acetate；前两项与酸度指标相符，第三项缺乏直接支持，入选率0.200 |
| 4VG感官 | 4-vinylguaiacol、Terpiryl acetate、Nerol；第一项与目标命名一致且200次均入选，其余两项仍需机制证据 |
| 金属感 | Iron、Ethyl 3-methylbutyrate、Isopentyl butanoate；Iron与目标描述相符，另外两项只能作为条件关联候选 |
| 双乙酰感官 | Eugenol、Beta-phellandrene、2-methyl-benzofuran；三项均缺本次参考描述的直接支持，且系数均为负，不能称为奶油味的直接生成原因 |
| 纸板/陈化感官t2n | Germacrene D、Glycerol、α-phellandrene；不能据模型排名把这些候选写成nonenal的同义物或已确认陈化机理 |

命名指标核对表显示，Diacetyl、DMS和E-2-nonenal并未进入对应感官目标的Ridge Top-3。保留这一结果，而不是用化学常识重排模型。它提示模型可能受到共线替代、弱信号或样本风格结构影响，需要实验干预才能进一步区分。

有1条描述相符候选的系数为负：orange目标中的2-ethyl-1-hexanol。它的柑橘描述并不能把负条件系数解释为“提高浓度增加橙味”；输出逐条提醒此差异。

## 稳定性结论

150条候选重训入选频率中位数0.3825，其中93条低于0.5。当前只交付条件于本模型和采样方案的候选，不能称为已经稳定识别全部关键化合物。

50目标平均Top-3 Jaccard：Ridge与完整森林0.122，完整与219列森林0.590，全局与同风格置换0.424。新增表保留每个目标的值。Ridge这150条候选中19条在同风格森林置换下重要性非正；这与历史交接中的“全局森林自身Top-3中12条非正”使用不同候选集合，不是同一计数的变化。

这组结果支持“多种相关化合物可作为预测替代、部分解释受风格构成影响”，不足以证明直接因果效应。同风格置换在稀有风格中扰动不足的限制仍保留。
