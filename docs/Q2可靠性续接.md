# Q2续接：候选口径、风格内证据与多重检验

2026-10-25：本实验的统计证据已合入[任务4主表](Q2主表与覆盖缺口说明.md)，严格/IBU家族两口径仍分开，原1999次置换与200次重训不为整合而重复运行。

本轮结果为`outputs/q2_reliability_20261024/`。沿用固定alpha=1000的稳健Ridge，研究已有解释为何不稳定，没有引入新预测算法或重新调参。原`q2_delivery_20261024`结果保留。

## 一个具体的候选口径问题

附件1字段`bitterness`在附件8命名为Iso-alpha acids、单位IBU。此前单体候选口径将其作为整体指标排除，因此旧苦味Top-3为Iron、Ethyl octanoate、Ethyl decanoate。

这不是同一个字段同时用作输入和感官真值：输入是化学/苦度测量，感官目标为附件4的`bitternes`。原研究也指出异α酸测量与苦味感知关联。[原研究](https://www.nature.com/articles/s41467-024-46346-0.pdf)

本轮增加独立口径：在原219项候选上，允许这个化学家族指标，共220项。它不是单一分子，IBU也不能等同于已确认单位下的纯异α酸浓度；不把pH、色度或其他综合量一并加入候选。

新口径苦味Top-3为Iso-alpha acids（IBU指标）、Iron、Ethyl octanoate；异α酸指标入选率0.995，200次重训符号全部一致。7个目标的Top-3受口径影响，其余43个不变。这是符合数据语义的补充，不用它覆盖或掩盖旧口径。

## 为什么需要风格内置换

只在风格内bootstrap保留了风格之间的差异。即使没有可重复的同风格内化学-感官对应，跨风格差异也可能使某候选稳定入选。因此入选率高不能单独证明更直接的关联。

新检验固定X、变换和alpha，每次将整行50维感官标签在同风格内共同置换，保留各风格样本数、风格均值结构和标签间关联，破坏同风格内的样本配对。共1999次，原候选参数在运行前固定。

每个目标使用所有可选输入中最大的绝对系数作为统计量。逐候选也与置换下的最大值比较，考虑从219或220项中挑选的影响。它检验的是“风格内配对可交换”的完整零假设，不保证部分零假设下的强家族错误控制，也不证明因果。

针对50个目标，另用Benjamini-Yekutieli方法校正，明确区分两种候选口径。置换P值采用`(1 + exceedances)/(B + 1)`，不报告零P值。最小可报告值为0.0005；这些小P值仍有Monte Carlo分辨率限制，部分校正结果接近0.05，不能称为对置换随机性完全稳定。

## 结果

原严格口径下，50目标没有一个BY q≤0.05；最小校正值约0.05624。允许异α酸家族指标后，下列5个目标的目标级检验得到名义q≤0.05：

| 目标 | 最大系数风格内P值 | 50目标BY q |
|---|---:|---:|
| 苦味bitternes | 0.0005 | 0.037493 |
| 4VG感官X4vg | 0.0005 | 0.037493 |
| 酒精感alcohol | 0.0005 | 0.037493 |
| 金属感metallic | 0.0010 | 0.044992 |
| 橙味orange | 0.0010 | 0.044992 |

这是目标级证据，不能据此说这些目标全部3项因素都通过了检验。新增一个有明确物理含义的指标会改变该目标最大统计量，也会改变50目标校正中的排序；两种口径是不同检验族，不能把“0到5”当成独立验证的模型性能提升。

新口径的异α酸指标在乳酸感、醋酸感等目标也常入选，且系数为负。然而其相应候选最大统计量P值约0.602和0.855，缺少超出风格结构的证据。原研究讨论酒花与酸啤风格、微生物等关系；本数据不能据此确定哪种机制导致条件关联。不能将这些负系数写成在本数据上已证实的抑酸效应。

原150项候选中，17项达到未经跨目标校正的候选最大统计量P≤0.05。这一计数不等于17项独立发现；完整结果含未通过项。

## 为什么没有用文献强行补满Top-3

命名物质在原模型中可能排得很低：Diacetyl在同名感官目标的219项绝对系数排名为149，DMS为53，E-2-nonenal在t2n目标为152。它们对应的边际关联也很弱或方向不合简单直觉。加上dms、t2n等目标的OOF预测能力低，当前资料不足以可靠识别这类目标的直接化学因素。

本轮没有用“已知该物质通常具有某味”来覆盖实际统计结果，也没有把114条直接证据不足项重新标成已证实。现在可以区分：候选口径导致遗漏、符号稳定但主要反映风格结构、超出风格结构的统计证据，以及仍需外部实验证据的关系。
