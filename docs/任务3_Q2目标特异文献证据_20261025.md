## 重建与核验

在仓库根目录、已按requirements-lock.txt安装依赖的Python环境中执行，无需重新联网或重训。本机使用`.venv/Scripts/python.exe`：

```powershell
.venv/Scripts/python.exe scripts/task3_q2_literature.py --output outputs/my_task3_literature
.venv/Scripts/python.exe scripts/task3_q2_literature.py --output outputs/my_task3_literature --verify-only
$env:PYTHONPATH = 'src'
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

输出目录须不存在；`--verify-only`只读核验已有结果。核验对原Q2输入的解析单元格做语义哈希，容许Git换行转换但不容许数据内容改变。校验原150行全部46列、156位置及6个空排名，并核对48条配对、来源ID和保存后的所有新表。该程序验证台账一致性，不能自动验证文献科学解释；这些解释需队员对照所列原文复核。

本阶段全部新表只读核验通过，103项既有单元测试通过。没有重复执行模型训练或19步整链；既有模型及统计结果没有修改。
