# Q3：修复误拦、处理缺失，采用实测参照迁移

后续接手复核补充：《本轮复核与参照风险.md》新增留出诊断和声明范围检查，未获得参照校正的预测优势支持，1%IQR模型范围情景仅10款通过。下文11款是名义方案，不应脱离新诊断引用为可靠预测或物理保证。

本轮对应用户指出的三个问题。上轮把较低的缺陷值也当成“偏离Tripel范围”而阻断，属于建模条件设置不当，本轮修正。已为全部11款Pils/Lager交付两套完整迁移谱和感官画像；Stale hops增加了必要的中位数基线及绝对误差对照，并提出依赖实测参照的迁移方案。原实验保留用于追溯，论文不在本任务范围内。

## 1. 六款“范围冲突”已解除

beer81、185、90的DMS，以及beer124、218、230的E-2-nonenal都**低于**实测Tripel的最小值。较低的缺陷值符合“不恶化”的方向，没有理由为了达到目标风格的经验下限而把缺陷升高。

修正规则：220项非保护坐标仍受Tripel逐列上下界约束；四个保护坐标保留上界，允许低于Tripel经验下限，并要求不高于源值。路径算子比较“源值精确保留”与“取路径值和源值的较小者”，均不会增加保护坐标。原来的224项硬下限情景只作为历史敏感性记录，不再推荐作为迁移验收条件。

对于任意正阈值T，`e(c,T)=max(c/T-1,0)`随c单调不减。因此，只要浓度不增加，超阈值严重度就不会增加；不需要为了比较大小臆造nonenal阈值。在同一化合物具有固定单调变换的假设下，原坐标非增加也有这个性质，log10/ln的底数不影响大小方向。该推导不解决不同字段的单位冲突或实际生产控制问题。

## 2. 两款缺失采用有来源的零上限

缺失发生在beer119、28的`X2.3.butanedione`。附件8的`Calibrated chemical dataset`对应同款啤酒记录均为0。逐行来源、Excel行号和附件哈希记录于`source_defect_evidence.csv`。

本轮对这两款的迁移后Diacetyl设置0上限。在非负浓度及该字段采用浓度坐标的假设下，即便源CSV的未知真实值大于0，目标0也不会使其恶化。代码只对“Diacetyl缺失且附件8明确为0”的情况应用此规则；没有泛化成缺失填0。源CSV不修改，也不声称补回了原始测量值；字段`raw_measurement_recovered`始终为false。

附件8和原坐标对照：DMS正参考249/249符合log10；4VG正参考82/82符合log10；Diacetyl可比241项中238项符合identity；nonenal可比249项中247项符合identity（容差1e-6）。5项不一致另表保留，已观测源值不自动覆盖。两个缺失Diacetyl的校准表0被用于保守设计上限，不能当作所有校准争议已经消失。

## 3. Stale hops：纠正基线判断并调整迁移方法

“预测仍弱”具体指模型不能稳定优于简单常数预测，R²也很低。上轮只对照均值不够，本轮补上更适合偏斜目标和MAE评价的训练折中位数。为核查损失不匹配，再比较固定参数绝对误差树和绝对误差提升树，均使用原3折、折内填补，没有重复调参。

| 方法 | OOF MAE | OOF R² |
|---|---:|---:|
| 训练折均值 | 0.308970 | -0.003792 |
| 训练折中位数 | **0.283424** | -0.125683 |
| 原多目标模型 | 0.308347 | 0.013986 |
| 单目标平方误差树 | 0.299150 | 0.036297 |
| 单目标绝对误差树 | 0.298113 | 0.025288 |
| 单目标绝对误差提升树 | 0.284701 | 0.019595 |

绝对误差树继承300树、叶最少3样本、max_features=0.7，仅改变损失；提升树为200树、深度2、学习率0.03、叶最少5样本、absolute_error。两者与中位数的MAE差95%固定OOF分层bootstrap区间均含零。新增模型没有部署为“更可靠的Stale预测器”，不通过只换指标或忽略中位数来宣布改进。

为减少迁移对全谱弱预测器的依赖，采用**实测Tripel参照 + 四项局部修正**：

1. 候选参照只用224项数据全部完整的23款真实Tripel，排除5款存在缺失的目标样本。
2. 其余220项坐标保持参照的实测值，四项缺陷取`min(源上限, 参照值)`，所以相对源和参照均不增加。
3. 参照实测Stale评分不得高于源的实测评分；两个风格分类器均须判为Tripel，且距离目标中心较源改善。
4. 每个已有预测器仅估计从参照到四项调整后谱的局部改变量。以参照实测评分校正：`S_after(m)=S_reference_observed + f_m(x_after)-f_m(x_reference)`。要求三个校正后估计的最大值不高于源实测评分。
5. 在可行参照中仍最小化原`0.7×目标中心距离+0.3×源改动距离`，不按成功率重新调权重。

这里把“参照处模型误差在局部调整后保持不变”作为显式模型假设。三个点估计的最大值只是模型分歧包络，**不是置信上界**。它没有对应的成对干预验证，不能由本轮结果推出真实Stale绝不升高。对实测参照的筛选属于设计过程，11款通过率也不是样本外预测准确率。

新参照方案用源与参照的**实测评分**进行校正，旧的“源预测值与新谱预测值比较”单独作为诊断，避免将源预测偏差误当成事实。选中结果中beer96、209、90不通过旧绝对预测比较，但均通过新的三参照校正规则；两种约束不可混称。另一套修正后的路径方案仍完整保留旧三代理非增加规则，11款都通过。
