# 评委追问与应答卡（20261028）

> 给论文执笔/答辩用。每条给出：**问法 → 我们的答法 → 证据 → 别说什么**。
> 所有数字以 `deliverables/paper_handoff_20261028/论文取数与口径.md`（r2）与 `paper_claims.csv` 为准。

## 最高危 5 条（一被问就露馅的位置）

### Q1. "你们 0–6 的标签是哪来的？3.xlsx 里不是有评分卡吗？"
- **答**：3.xlsx 是**空白评分模板**（12 张卡 + summary 全为 0，评分格空、得分格公式默认 0），没有人工分。我们用的 0–6 标签来自题面数据集附带的外部原始品评记录（Zenodo DOI 10.5281/zenodo.23624915，`Raw sensory data anonymized.csv`，2,197 条、16 位品评员），按"啤酒内相对名次"还原为 0–6 等级。文中把它写成"标签为外部原始品评记录的相对等级近似"，并给出复算路径。
- **证据**：`docs/赛题验收口径.md`、`experiments/lead_review/q1/`（missingness/标签构造）、`outputs/q1_decision_det_20261028/protocol.json`
- **别说**："3.xlsx 提供了实测分"——这是全篇最容易被判"不合题意"的一句。

### Q2. "Q1 主表 MAE 到底是 0.39、0.41 还是 0.48？"
- **答**：三个数都真，是三套口径：ET 整数中位 0.3928（基线，永不输出 5/6）；历史批次 top-k 0.40648（把"本批多少格"当决策输入，批次相关）；**正式口径 0.47968（逐样本固定阈值，批次无关）**。正式口径是唯一可部署、同一模型对整批和逐条给同一答案的版本。论文以正式口径为主表，另两列作对照，并解释 trade-off：批次表在固定整批时多 0.073 MAE 优势，但逐条预测时 ≥5 分会全部消失。
- **证据**：`tables/q1__metrics_summary.csv`、`tables/q1__batch_invariance.csv`、`q1__thresholds.csv`
- **别说**：把 0.3928 当"我们的成绩"——它不含 5/6 输出。

### Q3. "5 分精确率 9.5% 是不是太低？之前不是说 26% 吗？"
- **答**：观测 ≥5 分只有 198/12,500（1.58%），且品评噪声使个体高分不可精确识别（个体层面信息下界 MAE 0.6636，个体 5 分质量约 82% 来自面板中位 <5 的啤酒）。批次 top-k 的 26.29% 依赖"整批数量"这个额外信息；改成逐样本固定阈值后，5 分数量不可控（clove 单维贡献 84/380），精确率回落到 9.47%，但召回从 0 变为 18.18%。论文把高分识别写成"受标注噪声限制"的局限，而不是卖点。
- **证据**：`tables/q1__metric_calibers.csv`、`outputs/q1_decision_det_20261028/summary.json::over_promotion_diagnostic`
- **别说**："我们能精确识别 5/6 分"。

### Q4. "Q2 有因果结论吗？"
- **答**：没有，也不声称。我们做的是共表达图 + Ridge 系数 + bootstrap 稳定性 + 证据分级（A/B/C，A 级 8 条全部有文献来源），只能说明"关联与结构位置"。图的作用经消融检验：稳定性频率 +0.028、Jaccard +0.032，但留出预测无显著提升（p=0.31），所以定位为"更稳、更可解释的结构先验"，结论标 `partial_gain`。
- **证据**：`tables/q2__top3_all50_150.csv`、`q2__stability_bootstrap.csv`、`q2_ablation__predictive.csv`、`q2_ablation__summary.json`
- **别说**："图提升了预测精度"、"X 导致 Y"。

### Q5. "33/33 是你们自己定的标准吧？"
- **答**：题面要求"迁移后缺陷化合物不恶化"。我们把它落成三个并列口径：A 超阈集合不扩张且严重度不增；B 逐项 e_after≤e_before（e=max(c/T−1,0)）；C 严重度加总。三条都 33/33，候选级 660/660。但两项不可判定：trans-2-nonenal 无阈值、Stale hops 无化学坐标，表里如实标 `unknown`，所以 claim_level 只有 9 条 `model_supported`、24 条 `conditional`。
- **证据**：`tables/q3_migration__results_33.csv`、`q3_migration__evidence.csv`、`outputs/q3_migration_20261028/verification.json`
- **别说**："五缺陷全部验证通过"——t2n 与 Stale 是 unknown。

## 次级 7 条

### Q6. "生成谱能直接酿酒吗？"
- **答**：不能声称。生成谱是统计参考，满足缺陷 cap 与支持域约束，但没有物理/感官验证（`physical_brewing_validated=False` 写在元数据里）。论文写成"可供工艺侧参考的候选谱"，不是配方。

### Q7. "为什么 Tripel 迁移后只有 1/11 被判成 Tripel？"
- **答**：风格分类器本身弱：ET 折外准确率 0.544、最近质心 0.224（22 类基线 0.124），且 logistic 判 11/11、ET 判 1/11，两种分类器结论相反。迁移的定义是"到目标质心 + 缺陷不恶化"，风格判定只作辅助证据，不作为成功判据；这也是风格可辨识度被写成"部分可辨识"的原因。

### Q8. "迁移到 Tripel 的平均距离只降 12.5%，合理吗？"
- **答**：λ*=0.55（2 款 0.50），因为再往质心走会触发缺陷 cap；Tripel 训练集 **0/28** 样本自身满足三缺陷 cap（质心 DMS 2.03×、双乙酰 6.27× 阈值），所以"典型 Tripel"与"缺陷不恶化"在数据上冲突。我们另外构造了缺陷安全参照（投影到 cap 的质心），到源距离只比原始质心远 0.05%，投影只改 6.47% 坐标、11/11 达 DMS cap → 说明几何上可以兼得，冲突来自数据本身。

### Q9. "有没有数据泄漏/过拟合？"
- **答**：标定与阈值都在训练折/折外预算（泄漏审计：扰动外层标签后预测 max|Δ|=0，`leakage_fix.perturbation_worst=0`）；Q3 生成用预注册替换门槛（13 条实质 + 1 条汇总，设计时用固定验证折诊断已主动披露）；交付层 `verify --models --source` 会真重放（12,500 + 15,000 行，max|Δ|≈1e-16）并校验模型 sha，不做静默回退。

### Q10. "评估指标为什么用面板中位？个体呢？"
- **答**：题面口径是"给每款啤酒每个感官维度的 0–6 分级"，即啤酒×维度；个体品评员层面即使把已观察面板中位当 oracle，MAE 也只有 0.6636，说明个体层面被品评噪声主导。个体指标在论文里作为"为什么不做个体预测"的证据，不作主表。

### Q11. "三问的模型是不是同一个？"
- **答**：Q1 是监督回归+决策层；Q2 是相关图 + 线性模型的属性重要性；Q3 是风格条件生成（PC 残差/混合分布）+ 迁移投影。Q3 的感官画像直接复用 Q1 的正式决策模型（`inference.run` + 同一 sha），所以三问在"感官评分"这一层是同一口径。

### Q12. "复现性怎么证明？"
- **答**：三层复现：`status`（只读）、`predict/render`（模型+输入）、`train/package/verify`（全链）。交付包 398 个文件带 sha256，`verify` 逐文件校验；`code/` 内可独立跑 `status`；全量 396 项单测（含 25 skip 的需外部附件用例）。

## 最容易被扣分的 5 句话（自查清单）

1. "3.xlsx 提供 0–6 真实评分" —— 错，是空白模板。
2. "我们的 MAE 是 0.39" —— 那是 ET 中位基线，不能输出 5/6。
3. "个体高分可以精确识别" —— 不可达，写明噪声下界即可。
4. "图提升了预测精度" —— 只提升稳定性，预测 p=0.31。
5. "缺陷全部验证通过" —— t2n 与 Stale 是 unknown，别扩大表述。
