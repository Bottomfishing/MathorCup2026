# GitHub仓库与复现

目标仓库：https://github.com/Bottomfishing/MathorCup2026

仓库包含源码、配置、测试、依赖锁定、阶段交接，以及当前有效实验的CSV/JSON结果和PNG/SVG图。结果为探索版，适用范围见README和各阶段交接。

本地保留但不上传：虚拟环境、Python缓存、joblib模型、NumPy二进制中间结果、重复源码快照、检查点压缩包、已被替代的开发输出。公开下载的参考Excel含参与者元数据，也不纳入仓库；下载方法见scripts/fetch_reference.py。原始比赛附件位于工作区外，不随仓库上传。

他人复现需准备原始附件，创建Python3.12环境并安装requirements-lock.txt，然后按README与阶段交接依次重新运行。使用新的输出目录，避免覆盖已发布的历史结果。模型和NumPy中间文件会在运行时重新生成。

历史manifest和模型路径保留原机器记录以便追溯；克隆后不能直接运行依赖未上传模型的历史重放验证。应先在本机重新训练，再对新输出目录运行对应verify脚本。历史检查点清单校验仅适用于原本地快照，不是克隆完整性检查。

尚未确认官方认可临时0～6相对等级；不能把生成谱、参考阈值情景或模型预测当作已认证的真实品评/酿造结果。
