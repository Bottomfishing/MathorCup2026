## 诊断结果

在原OOF记录上，以每折训练等级频率作先验基线。评价标准为归一化等级概率分数：六个累计概率与观测累计事件的平方误差平均，取值0～1、越低越好。标签仍是训练参考分布定义的相对等级。

45主目标共11,250项：模型RPS为0.166311，训练先验0.190748；差-0.024437，固定OOF风格内配对bootstrap区间[-0.026689,-0.022190]。它支持模型分布包含一些预测信息，不代表原始评分准确率或概率已经校准。

模型的等尾名义90%区间实际覆盖99.262%，平均宽度5.7166级（0～6总跨度6级）；先验区间宽6级、覆盖100%。覆盖高主要伴随很宽的范围，不能以此宣称高精度。此区间没有有限样本覆盖保证，也不是原始评分的置信区间。

逐观测等级、全部50目标、六个累计事件的分箱校准表和每条预测诊断均保留在`outputs/q1_probability_diagnostics_20261024/`。验证重算12,500条预测、1050条训练先验、18组指标及2000次抽样，verification.json为passed。

## 预测接口

显式加载带`grade_model`的直接分级模型时，长表增加：

- `relative_grade_forecast_lower90`、`relative_grade_forecast_upper90`：分布上的等尾区间端点。
- `grade_max_class_probability`：最高类别预测概率，尚未校准。
- `grade_probability_calibrated`：false。

`prediction_info.json`记录区间类型与名义水平。旧连续模型没有分类分布，因此不伪造这些区间；旧连续值、相对等级宽表和默认模型行为保持一致。

