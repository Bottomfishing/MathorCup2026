## 5. 复现（三层级）

```powershell
$env:PYTHONPATH='src'
# L1 只读：状态
.venv\Scripts\python.exe scripts\current.py status
# L2 重放：预测 + 渲染（只需模型与输入）
.venv\Scripts\python.exe scripts\current.py predict --task q1 --model outputs\current_models\q1.joblib --input <1.csv> --output <out>
.venv\Scripts\python.exe scripts\current.py render --models outputs\current_models --source "<附件目录>" --output outputs\render_closeout
# L3 全链：训练 + 打包 + 核验（需原始附件）
.venv\Scripts\python.exe scripts\current.py train --source "<附件目录>"
.venv\Scripts\python.exe scripts\current.py package --rendered outputs\render_closeout --output deliverables\current_20261028
.venv\Scripts\python.exe scripts\current.py verify --models outputs\current_models --source "<附件目录>" --package deliverables\current_20261028 --output outputs\verify_closeout
```

注意：`package` 要求目标目录不存在（存在会报 `FileExistsError`），重建前先删除旧目录；`verify` 的 `--output` 是本次核验报告的输出目录，不要与包目录混用。
