# 任务1：换行哈希复核修复

日期：2026-10-25。接手版本`c32e698`。本阶段只修复最新审查诊断结果的Git检出可移植性；用户要求完成后推送main并停止，任务2～6不自动执行。

## 原因与修复

现有配置清单记录的SHA对应LF字节，而Q3三个冻结输入CSV清单记录的SHA对应CRLF字节。Git未明确约束这些文件的检出换行：自动转换开启时配置核验失败，关闭时CSV核验失败。

新增根目录`.gitattributes`，精确指定：

- `configs/review_*_20261025.json`检出为LF（当前三个文件）。
- `outputs/q3_task3_20261025/transfer_source_profiles.csv`、`transfer_profiles.csv`、`transfer_results.csv`检出为CRLF。

该方式保留现有SHA和核验程序，未改原始赛事数据的字节校验，也没有重写历史结果或替换模型。当前工作区的三个配置已按新规则转为LF，语义内容不变。新克隆/新检出由Git自动采用规则；已有克隆如仍保留旧工作区换行，可对这三个已跟踪配置执行Git重新检出，但应先保存自己的未提交配置修改。
