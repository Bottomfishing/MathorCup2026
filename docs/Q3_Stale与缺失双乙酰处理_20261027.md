# 第二阶段：Stale与119号缺失双乙酰

本轮实际处理两项最影响结论的缺口。**119号不再依赖“源双乙酰=0”的数值假设来运行预测与建立四代理条件方案；真实双乙酰值仍未恢复。Stale专用方法未通过冻结的预测采用门槛，仍未解决。**不得将本轮写成完整五缺陷迁移成功。

当前119号取数入口为`outputs/q3_missing_aware_20261027/current_plan_status.json`及同目录CSV。源谱和目标谱的双乙酰列均保留NA，操作规则为“保持源实际未知值”，四项风险与风格使用针对该缺失情形验证过的223输入辅助模型。正式Q1的224输入模型不变，0～6评分画像单独保留。

## 双乙酰：移除的是零填补依赖，未删除化学约束

已直接核对附件1、附件8及原研究补充工作簿：119/28在原始化学表中同样缺失，校准参照表给0。它们是[同源原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10966102/)的版本，不是两次独立测量。本轮未找到能给119恢复原始数值或有据测量上限的记录，未把参照0、训练中位数或估计量当成实测值。

先对原224输入模型作了数据导出的区间检查：令源和目标的双乙酰输入同时为未知变量，其他坐标保持119号固定方案；区间为0至相容已观察输入最大值121.7310182。这是**模型输入支持范围，不是119号真实浓度界限，也不自动具有mg/L单位**。字典中的参考单位不能直接升级为原输入单位。

按森林可到达路径提取所有相关分裂，处理float32舍入边界，检查全部离散预测状态；Logistic风格用单变量logit端点界，距离及最近邻支持用解析边界检查。开发20模型检查1575个代表值、对照12模型1133个代表值。四项概率差80%分位数仍为负，但联合通过率在部分极端值处从10/12降到8/12，所以**没有靠事后截短区间，把“未知值可能较小”当成已经证明的上限**。普通NA输入通过训练填补时仍10/12通过，但这也未恢复真实化学量。

实际采用的修正是预测器输入与可用信息一致：同一类ET300及两个风格模型不使用缺失的双乙酰列，使用其余223列。化学约束仍是

`目标双乙酰实际值 = 源双乙酰实际未知值`。

CSV中两端保留NA，`transfer_rule.json`记录保留规则；不是令目标为0，也不是允许双乙酰增加。这个等式是化学目标约束，**尚非酿造工艺已实现它的实证**。模型不使用此列，仅消除了预测路径上的特定零值依赖；实际浓度及其真实感官作用仍未知。

## Stale：已训练，未达到采用依据

原始2197条记录中，Stale为0的1915条、非零282条；250款中245款的观察面板中位数为0。没有用大量零整数或低MAE证明其可预测。

预先固定`configs/q3_stale_missing_protocol_20261027.json`，有限候选为训练先验、同切分共享ET、24个预先标注aging属性上的两种正则强度Logit，以及aging/全部224属性上的单目标leaf10森林。未重复已证明失败的leaf1/3，不用品评员ID、风格、论坛描述或参照酒标签作预测输入。目标明确为真实0～6标签导出的个人评分≥1概率，**没有改造评分标签，也没有将其宣称为整数高分识别改进**。

三次重复、每次外3/内2折，在训练内按Brier选择候选。查看比较前固定采用要求：相对先验平均改善≥0.0005，99%区间下限>0，相对共享ET改善95%下限>0，各重复均改善，软标签AUC均值≥0.6且有足够预测变异。这些是团队采用标准，不是赛题分数线。

独立酒花酿造研究观察到老化支链游离酸及香气组分共同影响感官，且与组合、剂量有关，见[原始实验](https://brewingscience.de/index.php/brewingscience/article/view/101)。本题224输入未直接覆盖该研究的异丁酸、异戊酸、2-甲基丁酸；对应酯不是游离酸，现有aging注释也不是储运过程实测。文献只帮助解释信息缺口，不能替代本题Stale标签或证明其它代理永远不可能预测。

本轮有限方法的失败不证明Stale永远不可预测。当前结论仍是：**没有足够证据给本题Stale迁移风险提供可靠新判断，保留未知状态**。不把模型一致、非零概率下降、零整数或输入不变写成真实安全。
