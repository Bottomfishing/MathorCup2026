# 最终评价协议（20261028，T0）

本文件冻结"预测什么、如何评价、哪些是正式结果"，供 T1–T8 与论文取数统一引用。日期为真实日期；此前协议与失败记录保留为历史，不回写日期、不改写为事前设计。

## 1. 评价对象

| 层 | 对象 | 用途 |
|---|---|---|
| 主对象（Q1 正式） | 每款啤酒、每个可评维度的**加权面板中位等级**（0–6 整数） | 主指标与交付表 `estimated_grade_0_6` |
| 辅助估计 | 同一 beer×target 的**面板均值**（连续） | 仅作辅助列/标定讨论，不进主指标 |
| 个体层 | 单条品评记录（taster×beer×target）的 0–6 分 | 单独一层评价（个体 MAE、高分精确/召回），不与面板层混比 |

维度口径：评分卡 52 个命名项，其中 Aroma/Flavour 两个乙醛槽无同源标签，保留 NA；可建模/可评价目标 **50 项**（Aroma 15 + Flavour 15 + 其他 20）。250 款 × 50 = **12,500** 个可评单元格；全 52 槽台账为 13,000 行、其中 500 行为 NA。

## 2. 数据与披露

- 化学输入 224 列（231 列剔除 7 个汇总列），来自附件 1.csv；感官标签 0–6 来自 Zenodo raw（DOI 10.5281/zenodo.23624915）；3.xlsx 为空白评分卡模板（12 卡 + summary，全 0），**不能**当作标定锚或"官方标注"。
- 250 款啤酒、16 位品评员、2,197 条原始记录；题面写 226 款、表 2 写 Pearson，均与实际不符，论文按实际披露。
- 缺失：1.csv 73 格（0.125%，其中 amyl.acetate 27 格），7.csv 750 格（集中在 3 个 palate 列），4.csv 无缺失。填补只用训练折拟合。
- Q2 拟合对象是 4.csv 的标准化响应，与 Q1 原始等级任务是**互补任务**，不互相解释。

## 3. 划分与选择纪律

- 所有划分按 **beer** 分组：同一啤酒的全部品评员记录、重复记录、合并衍生特征同折。
- 外层 3 折、内层 2 折（`configs/final_protocol.json`）；种子固定 20261024；稳定性报告复用 3 次重复框架，不为凑数增加种子。
- 阈值、标定、候选选择、填补全部在训练部分完成；外层验证折只用于打分与报告。
- 正式 Q1 决策必须**逐样本确定**：只依赖当前样本的预测值与训练期冻结参数，不得依赖本次批次的样本数、排名或行号（T1 修复项）。
- 预注册采纳门槛（历史已冻结，不回改）：候选 MAE 至少改善 0.005、配对 bootstrap 95% 下限 >0、三次重复均改善、高分假阳性 ≤2%；Q1 面板均值直接回归的 gate4（round 后 ±1 不差于 0.9119）为绝对下限，不因结果放宽。

## 4. 指标表

每张性能表必须写明：标签对象、预测对象、样本单位、加权方式、折外/全量拟合、模型版本、是否参与选型。

**主表（面板中位层，折外）**：MAE、完全命中、±1、逐目标宏平均 Spearman、0–6 混淆矩阵、逐等级支持数/精确率/召回率、≥5 与 =6 事件精确率/召回率（同时给面板级与个体级口径）。

**辅助表**：面板均值 MAE（标定前后）、个体级 MAE/精确率/召回率/加权 AUC、缺失情景（5/10/20% 额外遮蔽）、逐目标/逐风格误差与样本量。

**报告原则**：小样本类别必须给分母；full-fit 展示表（250 款整体推断）不得进入任何折外准确率统计；Q1 高分格的 full-fit 数量与折外数量分列，不构成矛盾。

## 6. 方法贡献的验证边界

- Q2：共表达图 + 图邻域排名；需直接消融（邻域权重 0 vs 0.5）说明是否有增益；Jaccard 只表示相似度；非因果。
- Q3 生成：插值 / v2 donor 残差 / v3 混合 的同折同种子对照；v3 设计时使用过固定验证折的 v2 覆盖诊断，**不宣称独立泛化**。
- Q3 迁移：33 条案例分别报告"已知化学约束通过 / 目标风格支持 / 未知缺陷状态"，不把化学约束通过写成迁移成功率。
- 缺失与不可判定项（双乙酰缺测、t2n 无阈值、Stale 无化学坐标、两项乙醛无标签）一律保留为 unknown，不填零、不当安全。

## 7. 复现层级（T8）

1. **预测复现**：冻结模型 + 相同输入 → 相同输出（verify 重放，整数等级必须相等，概率容差 1e-12）。
2. **模型重建**：`current.py train --source 附件` 重建部署模型（需附件与 Zenodo 标签）。
3. **实验重现**：重跑折外指标、bootstrap、生成与迁移对照；与 1/2 不混称。
