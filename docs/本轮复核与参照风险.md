## 3. 从单点检查改为声明范围检查

对原11款实测参照候选，以每列全训练IQR的0%、0.1%、0.5%、1%、2.5%构造坐标扰动盒。非保护项与目标经验范围相交；四项缺陷仍有源和参照上限；浓度坐标的Diacetyl/nonenal另限非负。

这些幅度是敏感性情景，**不是测得的检测误差**。IQR为0的列不扰动，盒内不同化学量的组合也未证明具有真实可实现性。

范围算法：对Ridge的坐标单调变换和线性系数按符号取端点；对森林遍历盒可达叶，逐树取极值后求均值。森林的和式界可能保守，因为不同树未必在同一点达到极值。它是已拟合函数的确定性范围，不是概率置信区间。

| IQR半宽情景 | 三模型上界均满足参照校正规则 |
|---|---:|
| 0% | 11/11 |
| 0.1% | 11/11 |
| 0.5% | 10/11 |
| 1% | 10/11 |
| 2.5% | 10/11 |

beer124最薄弱，原单点余量0.002818。1%情景中存在一个显式Ridge端点，使其参照校正预测比源评分高0.003872；两个风格分类器在该点仍判为Tripel。端点谱已保存，它证明该声明坐标情景中存在**拟合模型约束反例**，不证明真实风味发生恶化。
