## 从新克隆开始

需要Python 3.12、原始附件1.csv至8.xlsx/数据说明.txt及原赛题PDF。PDF默认在附件目录上级，也可用`--statement`指定。

```powershell
git clone https://github.com/Bottomfishing/MathorCup2026.git
cd MathorCup2026
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe scripts/reproduce_current.py --source '原始附件目录' --output outputs/my_current_delivery
```

脚本检查Python主次版本、全部锁定包版本及`pip check`。缺少公开参考工作簿时通过既有脚本获取固定Zenodo版本并校验；已有工作簿可离线使用：

```powershell
.venv/Scripts/python.exe scripts/reproduce_current.py --source '原始附件目录' --reference '固定公开工作簿的本地路径.xlsx' --statement '原赛题PDF路径' --output outputs/my_current_delivery
```

输出目录必须不存在，不覆盖旧运行。日志在`logs/`；步骤失败或最终数值不一致会写`reproduction.json`为failed并退出。只有报告`status=passed`才代表本次整链通过。指定已有工作簿时核对固定SHA256，避免重复下载。
