## §1 全局口径与必须披露的事实

1. **数据规模**：题面写"226 款"，实际附件与 4.csv 是 **250 款**、22 个风格。论文写 250 款并加一句
   "以附件实际记录为准（题面 226 为概述）"，不要装作没看见。
2. **3.xlsx 是空白模板**：12 张评分卡（题面写 10 张）+ summary，评分格全为空/公式默认 0，**不含任何人工评分**，
   不能当 0–6 的标定锚。0–6 标签只来自外部同源公开数据 **Zenodo 23624915（Raw sensory data anonymized.csv，
   2197 条品评记录、16 位品评员、latin-1 编码）**。论文必须用一段"数据来源与标签构造"如实披露，并说明
   该数据与赛题附件为同一批次的匿名化原始记录（表 8 / 4.csv 与之可逐维对齐，见 §2.4）。
3. **可评维度 = 50**：评分卡 52 个槽位 = 47 主要内容 + 5 补充（alcohol/aftertaste/body/co2/overall）；
   其中 Aroma/Flavour 两个 Acetaldehyde 槽位在原始品评数据中无对应记录，标 NA，**实际可评 50 维 × 250 款 = 12,500 格**。
4. **2.csv 不是 Pearson**：按位置逐元素核对，2.csv 与 1.csv 的 **Spearman** 相关矩阵最大绝对误差 6.66e-16；
   题面写 Pearson 是笔误。论文注明"附件 2 为 Spearman 秩相关矩阵（实测复核）"，这本身是个加分的数据核对点。
5. **缺失分布**（Q1 的核心卖点，见 §2）：
   - 4.csv（标准化感官标签）：**0 缺失**；
   - 1.csv（化合物输入）：73 格缺失（0.125%），其中 226 个模型输入列内 60 格，`amyl.acetate` 27 格 = 10.8% 最高；
   - 7.csv（标准化感官原表）：750 格（1.60%），全部集中在 `palate_acetaldehyde / palate_acetate / palate_dentist`
     三列（各 250/250 全缺），因此不影响以 4.csv 为目标的分析。
6. **单位**：DMS µg/L（阈值 17.25 均值口径 / 19 中位口径，论文统一用均值口径并注明）；Diacetyl、4VG、t2n 为 mg/L
   （阈值 0.29925 / 0.09、0.206333 / 0.20、t2n 无阈值）。**注意 Diacetyl 坐标列与浓度列单位不同**，
   迁移计算必须先换算，否则会出现"浓度 0.3 却判超 0.9 阈值"的矛盾（团队早期用过有单位 bug 的中间产物，已弃用）。

## §2 Q1：感官评分预测（主表在 `tables/q1__*`）

### 2.1 论文应当采用的评估口径（最重要）

题面要求的是"给出 250 款 × 约 40 维的 0–6 分级评分结果"，**评估单位是啤酒×维度**，不是"某位品评员打了几分"。
把个体品评员 MAE（0.795）当主指标是自伤：同一款酒 16 位品评员的评分本身标准差就很大，
即使**直接使用已观测的面板中位数**（相当于偷看答案），个体级 MAE 也只能到 0.6636 —— 这就是个体级的信息下界。
论文应把"个体级评分不可精确预测"写成**数据特性/讨论**，而不是模型失败。

### 2.2 主表与主指标（可直接抄进论文）

- 主表：`tables/q1__submission_long_12500.csv`（`beer, target, target_family, grade_0_6, probability_rating_ge5, probability_rating_6`）
- 宽表：`tables/q1__submission_wide_250x50.csv`（250 行 × 50 维，可直接作为"提交结果表"）
- 主指标（啤酒级，OOF，n=12,500）：

| 指标 | 旧整数中位（团队原交付） | top-k 决策（建议主表） |
|---|---|---|
| 面板中位 MAE | 0.3928 | **0.4080** |
| 完全命中率 | 74.13% | 73.88% |
| ±1 命中率 | 91.69% | 91.31% |
| 逐目标宏平均 Spearman | 0.3283 | 0.2903 |
| 预测出 5 分的格数 / 精确率 / 召回 | 0 / — / — | **204 / 25.5% / 26.3%**（基准率 1.58%，lift ≈16×） |
| 预测出 6 分的格数 / 精确率 / 召回 | 0 / — / — | **16 / 6.3% / 5.3%**（基准率 0.15%，lift ≈41×） |

> 写法建议：主表用 top-k 版本并如实写"为覆盖 5/6 档付出 MAE +0.015 的代价"；或主表用旧整数中位、
> 另列 `probability_rating_ge5/6` 作为"高分潜力"，两种都行，**关键是不要出现"召回 = 0"这种自证失败的表述**。

参考基线（说明模型不是白给）：全零基线 0.8994 / 64.1% / 71.7%；训练先验中位数 0.6533；
面板中位 oracle 0.4437（不可达上界）。等级分布：观测面板中位 0:8013 / 1:954 / 2:1347 / 3:1367 / 4:621 / 5:179 / 6:19。

### 2.3 两个真正的技术贡献（论文的"创新点"就写这两条）

1. **决策层修正**：整数条件中位数在结构上**永远不会输出 5/6**（中位数落在 0–4），于是"5/6 精确召回 0"是决策伪失败。
   改为"逐目标/逐折按训练折观测率定 k，按 P(6)、P(≥5) 取 top-k"后，5 分精确率 25.5%、6 分 6.3%，
   且整体 MAE 仅 +0.015。这说明模型排序信息是有的（面板级逐目标 AUC：P(≥5) 0.807、P(=6) 0.829），
   缺的只是一个不截断的决策层。
2. **折外逐目标标定**：原始 ET 输出的"面板均值"列（0.6123）竟不如朴素目标均值基线（0.5493），是真实短板。
   用折外逐目标线性标定 → **0.5027（−17.9%）**；再加风格先验收缩 → **0.4622（−24.5%）**，±1 从 91.7% 提升到 93.1%。
   表：`tables/q1__calibrated_panel_mean_12500.csv`、`tables/q1__metrics_summary.csv`。
   （注意：标定后的等级列 MAE 会变差，论文里它是"连续分数列"的改进，不要混进等级表对比。）

### 2.4 缺失数据条件下的稳健性（本题题眼，必须有一节）

- 额外模拟 5% / 10% / 20% 输入缺失：连续 MAE 0.344510 / 0.347399 / 0.352589（相对完整数据 +0.69% / +1.53% / +3.05%），
  等级变化率 6.19% / 10.62% / 18.69%（注：这是**标准化相对等级尺度**的连续 MAE，与 §2.2 的 0–6 等级 MAE 不可直接比较，
  论文里要写清尺度）。→ "缺失率 ≤10% 时结论稳定，20% 时等级开始漂移"。
- 尺度可辩护性：4.csv 标准化值 z 与原始面板均值逐目标 Pearson **均值 0.9668 / 中位 0.9772**（50/50 维 >0.9，6 维 >0.99）；
  用 10 个锚点做 z→0–6 线性映射，留出 240 款 MAE 0.1362，舍入回整数后完全命中 61.0%、±1 95.2%（常数基线 0.5472）。
  → 说明"标准化标签 → 0–6 分"这条映射链是可辩护的，而不是硬凑。

### 2.5 Q1 不要写的话

- ✗ "个体品评员 5/6 精确召回为 0" —— 换成"个体级评分受品评噪声限制（信息下界 0.664），本模型个体级 MAE 0.795"。
- ✗ "3.xlsx 提供标定/锚点" —— 它是空白模板，必须如实说。
- ✗ 任何"因果"表述 —— 本题是预测/相关，不是因果识别。
- ✗ 把不同口径的 AUC（0.694 与 0.807）混用：0.807/0.829 = 面板级·逐目标宏平均；
  0.659/0.576 = 个人级宏平均；0.906/0.936 = pooled（被基准率抬高，别当头条）。

## §3 Q2：化合物—感官 Top-3（主表在 `tables/q2__*`）

### 3.1 方法与口径

- 共表达图：2.csv Spearman，|ρ| ≥ 0.5 → **231 节点 / 645 边 / 60 个社区（Louvain）**，最大社区 29 节点，平均度 5.58。
- 打分：Ridge（α=1000，219 个可排名化合物）系数 + 图邻域加权 `score = |β| + 0.5 × 邻居平均 |β|`。
- 覆盖：**50/50 维 × Top-3 = 150 条，无空位**（旧"17/50"是 GBR 原始分表的子口径 + 未补零归因，不是题面要求；
  团队 Ridge 主表本来就是全 50 维，这一点论文要写清楚，别让评委以为没做完）。
- 稳定性：200 次按啤酒 bootstrap；多方法（graph-ridge / ridge / ExtraTrees / 边际 Spearman）6 对 Jaccard。
- 化学合理性：每对"化合物—感官维度"给证据等级 A/B/C + 置信度 + 机制说明（`mechanism_class`、
  `target_semantic_match`、`off_flavors` 列），A 级可逐条辩护。

## §4 Q3：风格条件生成与跨风格迁移（主表在 `tables/q3__*`）

### 4.1 口径先对齐（这是 Q3 能不能得分的关键）

题面原文："以 tasting_category_fine 为风格标签，学习风格条件生成模型……同时做跨风格迁移（**如**把 Pils/Lager
的化合物谱'迁移'为 Tripel 风格，保持缺陷化合物不恶化）。**注：缺陷化合物以所列 DMS/Diacetyl/4VG/
trans-2-nonenal/Stale hops 等超阈值项为准**"。

- "如"= 举例，**做一个方向（Pils/Lager → Tripel）即满足题面**；论文做了一个方向 + 另两个方向作扩展，是加分。
- "超阈值项为准" = 判据是**超阈集合不扩张、严重度不增加**，不是"五项校准概率逐项不增"。
- "Stale hops" 在 1.csv 里**没有化学坐标**（只有 6 个 stale 相关酯/环氧化物列），t2n **没有阈值**——
  论文要写明"这两项以代理坐标 + 保守判据（不新增超阈）处理"，不要假装有阈值。

### 4.2 迁移结果：33/33 全通过（可直接做主结论）

- 3 个目标风格（Tripel/Kriek/Lambic）× 11 款 Pils/Lager 源酒 = **33 条迁移**。
- 三种判据全部 33/33 通过：A（超阈集合不扩张 + 严重度不增）、B（逐项 e_after ≤ e_before，团队原口径）、
  C（严重度加总不增）；候选级 20 个 λ 网格 × 33 = **660/660** 全通过。
- 迁移幅度：Tripel λ*≈0.55（96/139 为 0.50），到 Tripel 质心距离 **↓11.6–13.2%**；
  Kriek λ*=1.0、↓99.3%、11/11 判 Kriek；Lambic ↓65–92%（风格判别只有 2/11，论文如实写并解释判别器不可用）。
- 缺陷压制实例：Tripel 方向 DMS 3 款超阈压到 17.10（阈值 17.25）；双乙酰 4 款压到 0.081（阈值 0.09）；
  119 号 4VG 0.1438 → 0.0405（阈值 0.206）。
- 表：`q3__migration_33cases.csv`（含 `DMS_b/_a`、`Diacetyl_b/_a`、`4VG_b/_a`、`t2n_b/_a`、`dist_reduction_pct`、`lambda_star`）。

### 4.3 "0 候选"怎么解释（这段写好了是加分，写不好是硬伤）

团队旧口径在 `all_five_calibrated_probabilities` 阶段一次归零。复核发现：
1. 前一阶段（坐标上下限 / 目标范围 / 双风格模型 / 五项原始等级）每款源酒还有 **12–2735 个候选**，不是数据无解；
2. 归零来自自设的"五缺陷**校准概率**不增 + 双风格模型判目标"，题面没有要求；
3. 更关键的数学冲突：**Tripel 自身 DMS 中位 38.69 µg/L = 2.24 × 阈值**，"迁到 Tripel 质心"与"DMS 不升"
   在坐标空间里结构性互斥；缺陷安全点最近的质心其实是 Brett/cofermented。风格在 231 维坐标空间几乎不可辨识
   （最近质心 LOO 0.132、logistic 0.160、基线 0.124）。
4. 结论写法："**更严的工程安全门（五缺陷校准概率不增）必然 0 通过，这正说明题面口径（超阈值项）是合理的**"，
   并给出上述冲突分析 —— 这展示了对数据的深入理解，比硬凑一个有问题的方案更安全。

### 4.4 生成质量：现在的插值谱有数学缺陷，建议换生成器（论文可写成"诊断 + 改进"）

| 方法 | 方差比（应≈1） | 近重复率 | 边缘 W1（越小越好） |
|---|---|---|---|
| 团队现用插值（team_interpolate） | 0.55–0.60 | 0.7–3.2% | 0.136–0.139 |
| 2-donor 凸组合复现 | 0.54–0.58 | 0.6–2.2% | 0.11–0.17 |
| **copula + 分位数匹配 + 缺陷投影** | **0.948–0.975** | **0** | **0.020–0.062** |

插值谱方差收缩是凸组合的**数学必然**（已用 2/3-donor 复现），不是实现 bug。建议的生成器：copula + 分位数匹配 +
缺陷投影，方差比 0.95–0.97、近重复 0、边缘 W1 降一个数量级。若时间不够重跑 300 条官方谱，
论文里写成"生成诊断"一节并说明推荐方案，也比不提高。表：`q3__generation_quality.csv`。

### 4.5 Q3 不要写的话

- ✗ 把"0 完整候选 / 仅 119 号条件案例"当主结论 —— 会被判"Q3 未完成"。
- ✗ 声称做过真实酿造验证 —— 所有结果都是坐标/统计空间，不是实测。
- ✗ 忽略 t2n 无阈值、Stale 无坐标这两个数据事实（主动说明是严谨性加分）。
- ✗ 用"风格判别器判为 Tripel"作为迁移成功的主要证据（LOO 0.13，不可信）；主证据用质心距离下降 + 缺陷判据。
