## 从新克隆开始

需要Python 3.12及原始附件目录（1.csv至8.xlsx、数据说明.txt）。源数据保留在仓库外。PowerShell：

```powershell
git clone https://github.com/Bottomfishing/MathorCup2026.git
cd MathorCup2026
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe scripts/reproduce_delivery.py --source '原始附件目录' --output outputs/my_reproduction
```

输出目录必须不存在。流程会获取已固定校验和的公开参考工作簿，重建当前模型和交付表，检查科学数值是否与已提交结果一致；日志和最终状态见输出目录中的`reproduction.json`。源数据、模型二进制和下载的参考工作簿不随Git上传，运行时自行提供或重建。

仅需单阶段运行、调用新样本预测或重画图时，使用对应交付说明里的命令。旧脚本可能记录原作者机器路径；上述入口和当前交付脚本使用显式路径，不依赖旧joblib。

Q2续接：[可靠性研究](docs/Q2可靠性续接.md)补充异α酸IBU家族指标和风格内置换检验，保留严格单体口径。1999次置换及200次重训已完成，当前64项测试通过；目标级统计支持与直接化学因果证据分别报告。

Q3续接：[风格与约束研究](docs/Q3风格与约束续接.md)。风格判别OOF准确率从39.6%提高到60.0%；新增3款同时满足经验范围、双分类器和三Stale代理约束的候选。Stale单目标模型改善仍不确定；66项测试及独立环境折模型重训核验通过。

Q3约束修正：[11款方案及实测参照说明](docs/Q3约束修正与实测参照方案.md)。解除“缺陷低于Tripel经验最小值”的误拦，对两款缺失采用附件8支持的Diacetyl零上限。中位数基线揭示Stale回归尚无可靠改进，新增23款完整实测Tripel参照与局部校正，11款均有方案；70项测试及两套候选独立核验通过。参照校正仍需显式假设，没有迁移后实测保证。
