## 从新克隆开始

需要Python 3.12及原始附件目录（1.csv至8.xlsx、数据说明.txt），原赛题PDF放在附件上级或通过`--statement`指定。源数据保留在仓库外。PowerShell：

```powershell
git clone https://github.com/Bottomfishing/MathorCup2026.git
cd MathorCup2026
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe scripts/reproduce_current.py --source '原始附件目录' --output outputs/my_current_delivery
```

输出目录必须不存在。流程获取或校验固定公开工作簿，重建选定模型及当前交付表并核验科学数值；Q2既有重采样/置换及Q3补充参照诊断按版本复用，范围见本次`reproduction.json`。已有工作簿可用`--reference`离线传入。源数据、模型二进制和下载工作簿不随Git上传。

仅需单阶段运行、调用新样本预测或重画图时，使用对应交付说明里的命令。旧脚本可能记录原作者机器路径；上述入口和当前交付脚本使用显式路径，不依赖旧joblib。
